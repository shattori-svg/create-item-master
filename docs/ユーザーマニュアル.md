# 商品登録 取り込みファイル作成システム ユーザーマニュアル

基幹システム（Business Central）向けの商品登録インポートファイル（.xlsx）を作成する Web アプリの使い方です。  
グロサリー部門のメーカーバーコード商品を対象とし、日本語・タイ語に対応しています。

**アプリの URL**: https://item-master-create-dev-894174291476.asia-northeast1.run.app/

---

## 1. システムを開く

ブラウザで上記 URL を開いてください。

---

## 2. 言語の切り替え

画面右上の **日本語** または **ไทย** をクリックすると、表示言語が切り替わります。

---

## 3. 部門の選択

画面上部の **部門** ドロップダウンから、取り込み先の部門（01～06）を選択します。

---

## 4. 商品データの入力

入力フォームは 3 ブロックに分かれており、色で区別されています。順に入力します。

### 4.1 基本情報（ピンク系）

- **バーコード** *必須*
- **商品名（英語）** *必須*
- **商品名（タイ語）** 任意
- **分類コード** *必須* — 入力で検索可能。**AI推測** を押すと商品名から分類を提案（API 設定時）
- **規格（英）** / **規格（タイ）** — 初期値は 1pcs
- **税率** — 0% または 7% を選択

### 4.2 取引情報（黄系）

- **仕入先** *必須* — 名称・コードで検索可能
- **原価** *必須*
- **発注入数** *必須*
- **発注リードタイム（日）** — 初期値は 2

### 4.3 販売情報（緑系）

- **売価** *必須*
- **販売入数** *必須* — 2 以上にすると **ケースJANコード** と **ケース売価** が表示される
- **ケースJANコード** / **ケース売価** — 販売入数が 2 以上のときに入力
- **ケース商品名** / **ケース規格（英語）** / **ケース規格（タイ語）** — 任意
- **ブランド（英語）** / **ブランド（タイ）** — 任意

必須項目をすべて入力すると、**入力完了** ボタンが有効になります。

---

## 5. リストに商品を追加する

- 入力が終わったら **入力完了** をクリック（または最後の項目で Enter キー）
- 商品が右側の **入力済み商品リスト** の表に追加されます
- 最大 100 件まで追加できます

---

## 6. リストの編集・削除

- **編集**: リスト内の行をクリックすると、その内容がフォームに戻ります。修正後、**入力完了** の代わりに表示される **編集** ボタンをクリック
- **削除**: 削除したい行の左端のチェックボックスをオンにし、**削除** ボタンをクリック
- **全選択**: 表のヘッダー行のチェックボックスで、一括選択できます

---

## 7. ファイルのインポート（Excel から読み込み）

- **ファイルインポート** をクリック
- 本システムで出力した .xlsx ファイル（または対応形式）を選択
- **リストを置き換える** か **リストに追加する** を選ぶ
- リストにデータが読み込まれます（置き換えの場合は既存のリストは消えます）

---

## 8. ファイルの出力（Excel の作成）

- リストの内容を確認する
- リスト下で **Item** / **Additional Barcode** のどちら（または両方）をファイルに含めるか選択
- **ファイル名** を入力（空欄の場合は日時ベースの名前が使われます）
- **ファイル出力** をクリック
- .xlsx がダウンロードされます。Business Central の取り込み画面でアップロードして利用します

**注意**: リストに 1 件もない場合、または部門が未選択の場合は **ファイル出力** はグレーアウトして押せません。

---

## 9. その他のボタン・機能

| ボタン・機能 | 説明 |
|--------------|------|
| **AI推測** | 商品名から分類コードを提案（API 設定時） |
| **クリア** | フォームだけを空にして、新しい商品を入力できる状態にする（リストはそのまま） |
| **インポート画面へ** | ファイル出力後に表示。基幹システムの取り込み画面を新しいタブで開く |
| **閉じる** | ファイル出力完了メッセージを閉じる |

---

## 10. 注意事項

- 入力済み商品リストはブラウザのメモリ上のみで、自動保存されません。**ファイル出力** で .xlsx を保存するか、**ファイルインポート** 用のファイルを別途保管してください
- バーコードはリスト内で重複できず、チェックディジットの検証があります
- Cloud Run で AI 推測や Google スプレッドシートからの分類・仕入先マスタ取得を使う場合は、管理者が API を設定します
